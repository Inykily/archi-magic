# archi-magic glossary

Plain explanations of words that an architect will meet when using archi-magic. Each entry is one sentence.

| Term | Meaning |
|---|---|
| Claude | Claude is the AI assistant that reads your request and does the work. |
| Claude Code | Claude Code is the version of Claude that can run tools and work with files on your computer. |
| Plugin | A plugin is a package that adds new skills to Claude. archi-magic is a plugin. |
| Skill | A skill is a set of instructions that teaches Claude one job, for example "install pyRevit". |
| Marketplace | A marketplace is a list of plugins that you can install in Claude Code. |
| Terminal | A terminal is a window where you type text commands to the computer. Claude can use it for you. |
| Command | A command is one line of text that tells the computer to do one task. |
| Script | A script is a small file of commands that the computer runs from start to end. |
| Programming language | A programming language is a set of words and rules for writing scripts, for example Python. |
| Python | Python is the programming language that pyRevit uses for its tools. |
| pyRevit | pyRevit is a free add-in for Revit that adds tools and lets scripts work inside Revit. |
| Add-in | An add-in is extra software that adds tools to Revit, usually on a new ribbon tab. |
| API | An API (Application Programming Interface) is the set of commands that one program gives to other programs. |
| Revit API | The Revit API is the set of commands that a script can use to read and change a Revit model. |
| MCP | MCP (Model Context Protocol) is the connection standard that lets Claude use tools in other programs, such as Revit. |
| Agent Runtime | The pyRevit Agent Runtime is the part of pyRevit that lets Claude talk to the open Revit model. |
| Revit model | A Revit model is the building file that is open in Revit (an .rvt file). |
| Element | An element is one item in the model, for example a wall, a door, a room, a sheet or a view. |
| Category | A category is a group of elements of the same kind, for example Doors or Walls. |
| Parameter | A parameter is one piece of data on an element, for example Fire Rating, Mark or Level. |
| Transaction | A transaction is one group of changes to the model that Revit keeps or cancels together. |
| Keep / Discard | Keep / Discard is the prompt in Revit where you accept or cancel a change that Claude wants to make. |
| Read-only | A read-only request only looks at the model and does not change it. |
| Dry run | A dry run is a preview that shows what a change will do, without the change. |
| Undo | Undo (Ctrl+Z in Revit) cancels the last change that you kept. |
| AI provider | The AI provider is the company that runs the AI model. Your requests and the model data that Claude reads go to it. |
