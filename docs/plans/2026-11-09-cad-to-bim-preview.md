## Reviewed geometry and qualification contract

- Specify one source link UniqueId and level UniqueId plus elevation. Coordinates are Revit internal-axis positions expressed in millimetres (feet multiplied once by 304.8), with no survey or project-base transform implicit. The offline DXF acceptance fixture is independently drawn in mm with identity world transform, LINE coordinates in WCS, and room vertices converted from OCS using vertices_in_wcs, rejecting arcs, bulges, width and non-horizontal contours. Keep source primitive IDs distinct and values literal. Select a real linked ImportInstance as in model_health.py; its rounded link location is not geometric evidence. Use export_bim_json.py only as a read-only traversal reference. Select one measured transform strategy in host: symbol geometry and composed nested transforms, or model-coordinate GetInstanceGeometry with no additional transform. Prove translation, rotation and mirrored/nested instances, and measure both source and actual Revit axes on a nonzero level.
- Use immutable, regular local input snapshots, unique JSON fields, maximum 1 MiB per input and 2 MiB output, up to 400 segments, 32 room loops with 64 vertices each and 512 vertices overall, 128 mapped layers, and coordinate magnitudes at most 10 million mm. Reject nonfinite, zero-length and below-tolerance primitives. Check input bounds before pairwise work and abort when more than 4,000 wall pairs meet the geometric tests; reject excessive inputs without producing a partial preview. User supplies 0.1–25 mm tolerance, minimum wall overlap of at least 100 mm, and door setback. No implicit tolerances at write time.
- Compute wall signed perpendicular offsets in the common projected frame, require no side swap, and check both CAD faces against the expected type-width faces at both common endpoints. A projected tail beyond tolerance on either face makes that pair unresolved. Retain source IDs, overlap length, maximum residual and tail lengths. Reject any face participating in multiple candidates. Mark competing overlapping collinear or near-parallel wall footprints and interior crossings unresolved; allow disjoint collinear runs. An explicit door marker must lie wholly along one unique remaining host, fit width within tolerance, and stay at least the specified setback from either end. Reject overlapping door spans. Floor level Z must agree for all primitives within tolerance. Room loops require explicit closure, minimum area, no repeated or short edges, no touching or near-touching nonadjacent edges and a strictly interior point with tolerance to all edges. Reject overlapping, contained, touching and shared-boundary loops pending native circuit handling rather than silently double-placing separation lines.
- The artifact is a dedicated CAD layout proposal with no executable steps or approval; it is not an am-safe-change change-preview. It does not use the inventory CLI as geometry input. Test drawing primitives from real ezdxf files and compare to independently measured expected geometry, including asymmetric tail, reversed faces, width residual, dense limit, nonzero Z, overlapping hosts/doors and contour conflicts. Plan the native producer before releasing apply. Native route reads existing walls, doors, rooms and separation lines, binds provenance to each source piece, verifies actual width/type, wall location-line/height/offset and levels, blocks overlapping or manual conflicts, and proves a repeat run creates nothing. Verify actual finish faces, hosted opening position, room circuit and area, and affected adjacent geometry after Keep. Prove dry run, Discard and an injected late door or room failure leave all affected state unchanged. The offline PR only references #166.
- Native acceptance uses a pinned known-geometry DWG, linked through the real ImportInstance in a disposable model, with named layers, a translated and rotated insertion and known world points. Verify the exact merged host implementation on this fixture, including no duplicates from partial prior creation. The reverse Revit-to-DWG export remains a distinct #188 handoff.
