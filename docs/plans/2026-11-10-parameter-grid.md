## Reviewed implementation contract

- New snapshots use `kind: "parameter-grid-snapshot"`, `columns` (ordered distinct parameter names), `rows` (objects with exact string `id` and one string per column), and optional `read_only_fields`. The explicitly marked format enables the standard preview on both routes. Unmarked legacy CSV inputs and library functions retain their existing report shape. Example: `{"kind":"parameter-grid-snapshot","columns":["Mark","Comments"],"rows":[{"id":"101","Mark":"D01","Comments":"Review"}],"read_only_fields":["Mark"]}`.
- Get element IDs and exact parameter values from the model with the existing read-only pyRevit agent workflow. Use `inspect_elements` for spot checks up to 50 elements (am-revit-api-docs), or a scoped `run_query` to read values from explicitly chosen elements by ID. Copy an ID as decimal text at the source to preserve all 64 bits. Record ambiguous or unconfirmed fields as read-only. Never join display schedule rows to elements by row position. Document both editing routes with the fixture, the PowerShell renderer, ownership inputs and the safe-change preflight handoff.
- Read at most 2 MiB per input before decoding. Reject duplicate JSON keys, unknown keys, missing cells, non-string values, identity header aliases, malformed/duplicate IDs, and duplicate edits. Allow positive signed 64-bit IDs, up to 500 rows and 20 fields, 120 characters per field name and 2,000 characters per value. Require exact selected CSV headers, with a single Element ID header. Accept a subset of rows, using the baseline for omitted rows. CSV uses UTF-8 with optional BOM and newline-aware parsing. Import Excel columns as Text to preserve IDs and literal cell values. Normalize CRLF and CR to LF in both paths. Keep the existing comparison that disregards leading/trailing whitespace.
- Both routes reconstruct every baseline row in baseline field order before running the existing comparator. A JSON edit packet has exact keys `kind: "schedule-grid-edits"`, `snapshot_sha256` of the original file bytes, and `edits`, each containing string `id`, `field`, and `value`. Reject different snapshot bytes. Same-baseline replay is deterministic. Recheck read-only fields in Python and emit a blocking warning on attempted changes through either route.
- Produce one canonical row per Element ID and include every selected field, before/after and changed columns, with warnings keyed by element ID and ownership IDs for changed elements. Keep legacy per-cell `rows` and `counts`, and name their column labels `legacy_columns` in the new format. Use an empty `steps` array. Disable preview CSV/TSV for this recipe so untrusted cell text cannot be re-exported via the preview. The supported Excel route begins with the baseline export and Excel Text import.
- The grid is local and offline. Use a CSP that blocks network requests, embed inert JSON with every literal less-than sign escaped, and assign model text only to textContent/value. Page through 25 elements and retain edits across filters and pages. The download contains only edited cells, and its digest detects file mismatch. The digest grants no model authorization.
- Exercise reversed edit/CSV row order, multiple fields on one ID, an ID above JavaScript's safe integer range, Excel BOM and multiline Unicode, stale/malformed/forged packets, and hostile text in both rendered pages. Verify a read-only warning on the correct row. Verify ownership input generation using the preview. Publish fixture and exact commands so the flow is reproducible.
