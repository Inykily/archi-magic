1. Extend the existing model_health.py run_query entry point with an opt-in revit_link_audit input and optional bounded link_view_ids list. Reuse the link inventory and personal path classifier. Add result.revit_links with type records and instance records keyed by stable numeric IDs, including unplaced types, and separate view coverage. Include pinned, Shared Site value via BuiltInParameter.GEO_LOCATION, and link origin as observations. A site label, including localized text, is not proof of shared-coordinate placement. Preserve all existing metrics and default outputs. No new CLI, dashboard, filesystem writes, transaction, reload, network probe, or model modifications.
2. Read ExternalFileReference.PathType, GetAbsolutePath, GetPath, and GetLinkedFileStatus independently so one unavailable field does not erase another. Use RevitLinkType.IsLoaded separately with unknown distinct from false. Read resource references independently for IFC provenance and provider paths, never synthesize Loaded from a nonempty path. Classify IFC when source data identifies an IFC file and label evidence as filename or API evidence. Treat .ifc.RVT as a cache/name hint, not certain IFC provenance. Keep saved path type and resolved path class separate. Flag Windows profile and drive-local paths without checking disk/network. Recognize UNC, Revit Server and explicit provider schemes conservatively. Relative plus missing absolute path means location unknown. Return classification and evidence fields, not full paths or profile names. Avoid arbitrary external resource info and exception text in output.
3. Default the opt-in view audit to the current project view, and allow explicitly selected IDs. Validate DB.View, non-template and IsViewValidForElementIteration. For each selected view use one host-view FilteredElementCollector constrained to RevitLinkInstance. Report collector membership as potentially visible, distinct from hidden by element/category and not returned. An API error yields unknown. Unloaded links cannot be potentially visible. Do not claim rendered visibility, nested element visibility, or complete view coverage. Return both view and instance IDs and an explicit reason for unexamined rows. Cap 200 types, 200 instances, 10 views, 1,000 observations and 10 seconds of elapsed view work checked between API calls. Native calls may individually exceed the budget. Partial results are explicit and the ordinary audit incurs no additional work unless requested.
4. Test exact output through the actual query script with a fake DB and distinct loaded, missing, unloaded, ambiguous provider, IFC cache, nested/unplaced, 64-bit ID, personal path, UNC, relative, explicit hidden, potentially visible, and unexamined controls. Prove default path remains unchanged and that bounds and API exceptions cannot masquerade as complete success. Verify privacy with paths containing recognizable sensitive values. Compare actual disposable Revit results with Manage Links and view graphics in at least two views and with local RVT and IFC links; validate Shared Site and the observed transform against UI. Live fixture, Revit version, pyRevit engine and disposable host remain required to close #150.
5. Ship isolated with ordinary CI. Rollback by reverting the PR. Because opt-in and read-only, the existing default and the underlying model are unaffected by disabling the new input.
